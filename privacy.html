개인정보처리방침이용약관

1. 처리하는 정보와 목적

  • 접속 정보: 소유자 계정의 이메일, 계정 식별자와 인증 세션을 Supabase Auth에서 처리합니다. 화면에서는 접속 비밀번호만 입력하며, 비밀번호 검증은 Supabase가 수행합니다. 비밀번호를 사이트 소스 코드에 저장하지 않습니다.
  • 프로필과 캐릭터: 입력한 이름 또는 별명, 나이, 선택한 성별·MBTI·혈액형, 캐릭터 설명과 설정을 개인 화면 구성에 사용합니다.
  • 직접 입력한 기록: 일정, 할 일, 완료 상태와 레벨, 운동 계획·기록, 룰렛 선택 내역, 자료 링크·메모·PDF·이미지를 저장하고 다시 표시합니다.
  • 접속·보안 정보: 서비스 제공 과정에서 Cloudflare와 Supabase가 IP 주소, 요청 시간, 브라우저 정보, 오류·보안 로그를 처리할 수 있습니다.

2. Google Calendar 연동

Google 연결을 직접 승인한 경우에만 연동합니다. Google 계정 이메일, 캘린더 목록·이름·접근 권한, 일정의 제목·내용·장소·시작 및 종료 시간·식별자 등을 읽어 일정관리 화면에 표시합니다. 선택적으로 캘린더 표시를 끌 수 있습니다.

요청 권한은 계정 확인(openid, email), 캘린더 목록 조회(calendar.calendarlist.readonly), 일정 조회·변경(calendar.events)입니다. 현재 사이트에서는 접근 권한이 있는 캘린더의 일정을 조회·추가·수정하며, Google 일정 삭제 기능은 제공하지 않습니다. 변경사항을 저장하면 Google Calendar에도 반영되고, 기존 일정의 공유·참석자 설정에 따라 Google이 알림을 보낼 수 있습니다.

이 정보는 캘린더 연동 기능에만 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅, 신용 평가, 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 서비스로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

3. 저장 위치와 보호

직접 입력한 기록은 Supabase 데이터베이스에, 업로드한 파일은 비공개 Supabase Storage에 저장합니다. 프로필과 캐릭터 설정은 Supabase 계정 정보에 저장합니다. 개인 기록을 GitHub 저장소나 공개 웹페이지에 게시하지 않습니다.

Google 연동용 접근·갱신 토큰은 서버에서 AES-GCM으로 암호화해 Supabase에 저장하며 브라우저에 전달하지 않습니다. 연결한 Google 이메일도 함께 저장합니다. Google 일정 본문은 Google에서 조회해 서버를 거쳐 화면에 표시하고, 별도 일정 테이블에 지속적으로 복제하지 않습니다. 사이트에서 작성한 Google 일정은 Google에 저장합니다.

통신에는 HTTPS를 사용하고, 데이터베이스와 파일에는 계정별 접근 제어를 적용합니다. 다만 운영자의 관리자 권한으로 데이터에 접근할 수 있는 구조이며, 운영자도 읽을 수 없는 종단간 암호화 서비스는 아닙니다. Google 사용자 정보의 사람에 의한 열람은 본인의 구체적인 동의, 보안 문제 대응 또는 법적 의무 등 Google 정책이 허용하는 경우로 제한합니다.

4. 외부 서비스

  • Supabase: 계정 인증, 기록·파일 저장, Google 연동 서버 처리를 담당합니다.
  • Google: 사용자가 승인한 계정 확인과 캘린더 조회·변경을 처리합니다.
  • Cloudflare: 웹사이트 배포·전송·보안 및 공개 Substack 글을 불러오는 기능을 담당합니다.
  • Substack: 공개 글과 이미지를 제공합니다. 외부 이미지가 표시되거나 원문 링크를 열면 해당 서비스에 접속 정보가 전달될 수 있습니다.

외부 서비스는 서비스 제공·보안 운영에 필요한 정보를 처리하며, 해당 사업자의 인프라에 따라 국외에서 처리될 수 있습니다. 개인 기록이나 Google 토큰을 공개 글 피드로 보내지 않습니다. 서비스 제공과 사용자가 요청한 연동, 보안 대응, 법적 의무 이외의 목적으로 개인 데이터를 판매하거나 공유하지 않습니다.
