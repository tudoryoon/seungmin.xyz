# Seoul Food Map

The public `#food-map` view reuses all 448 stable station IDs from `stations.js` (2026-09-13 reviewed snapshot). No station is removed for being outside Seoul or for lacking ordinary daily service. The initial extent is Seoul; All fits the currently filtered stations, including outlying termini. Transfer complexes remain one marker, while same-name stations such as Sinchon and Yangpyeong remain separate.

447 coordinates come directly from the Seoul T-DATA source documented in `stations.md`. Dorasan's missing position is the station building centre at longitude 126.7098703, latitude 37.8986390, from [OpenStreetMap way 181444733](https://www.openstreetmap.org/way/181444733), retrieved via Nominatim on 2026-09-26. OSM data attribution: OpenStreetMap contributors, ODbL 1.0. The override is isolated in `food-map-core.js`; roulette IDs, selection odds and saved records are unchanged. Positions identify station complexes, not specific entrances. Service warnings are preserved.

Map engine: Leaflet 1.9.4, vendored from the official npm registry (`leaflet-1.9.4.tgz`), BSD-2-Clause license in `vendor/leaflet/LICENSE`. The published ESM/CSS distributions are minified with esbuild 0.25.12; JS uses `--bundle --format=esm --minify --supported:template-literal=false`. Only the map tab loads the JS engine and visible raster tiles. Tiles use the standard HTTPS OpenStreetMap endpoint, visible attribution and the browser's normal HTTP caching/referrer behavior. There is no tile proxy, offline download, prefetch job, geolocation request, API key or paid plan. Respect the [OSMF tile usage policy](https://operations.osmfoundation.org/policies/tiles/); availability is best-effort and high traffic may require another provider. Closing/backgrounding the tab removes the tile layer.

Search/filter and all 448 station selections work from local data even when tile loading fails; the map shows a retry action for failures. This release is the station-map foundation, not a restaurant database. Station detail explicitly shows no registered restaurants. No invented reviews, saved restaurants, Supabase changes or write controls are included.

Validation: `node tests/food-map.mjs`, `DOM_MODULE=/path/to/happy-dom/lib/index.js node tests/food-map-ui.mjs`, and `tests/realm-routing.mjs`. UI tests inject a fake Leaflet adapter so selecting all stations never downloads tiles. Browser QA covers ordinary interactive desktop/mobile views without bulk tile scans.
